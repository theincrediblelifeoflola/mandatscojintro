✨ FONCTIONNALITÉS
═══════════════════

Génération
├─ 11 types de mandats (arrêt, perquisition, saisie, réquisition, etc.)
├─ Formulaire dynamique avec aperçu en temps réel
├─ Export PDF avec QR Code d'authentification
└─ Export PNG

Authentification
├─ UUID unique par mandat généré
├─ QR Code inséré au bas du PDF
├─ Stockage persistant (localStorage infini)
└─ Immuable : impossible de modifier après génération

Vérification (Page publique)
├─ Accès libre : /verify.html
├─ Recherche par UUID ou scan QR
├─ Affichage du mandat original + métadonnées
└─ Confirmation : "Mandat authentifié" ou "Non trouvé"

🔐 STOCKAGE & SÉCURITÉ
════════════════════════

• localStorage : Chaque navigateur a son propre stockage
• Infini : Aucune expiration des mandats
• Immuable : UUID + timestamp pour chaque document
• Traçable : Impossible de falsifier sans l'UUID original
• Privé : Stockage local, pas de serveur de base de données

📱 UTILISATION
════════════════

Générer :
├─ Sélectionner le type de mandat
├─ Remplir les champs
├─ Aperçu en temps réel
└─ Cliquer "PDF" → QR Code généré automatiquement

Vérifier :
├─ Méthode 1 : Scanner le QR Code du PDF
├─ Méthode 2 : Aller à /verify.html?id=UUID
└─ Méthode 3 : Entrer l'UUID manuellement

🆘 TROUBLESHOOTING
═══════════════════

Problème : "Mandat non trouvé" en vérification
→ Le mandat doit avoir été généré sur ce navigateur/domaine

Problème : QR Code ne scanne pas
→ Vérifier que qrcode.js CDN est accessible

Problème : PDF n'exporte pas
→ Vérifier que html2canvas et jsPDF CDN sont accessibles

Problème : localStorage plein
→ Nettoyer l'historique du navigateur ou exporter les mandats
